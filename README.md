BackupMaster - это легкое консольное приложение на .NET, предназначенная для автоматического резервного копирования файлов в режиме реального времени.

## Особенности

* **Мониторинг в реальном времени:** Использует FileSystemWatcher для мгновенного обнаружения изменений.
* **Механизм Debounce:** Бэкап запускается не мгновенно, а через 10 секунд после последнего изменения. Это предотвращает создание десятков копий, пока игра записывает файлы.
* **Безопасность:** Все пути к папкам вынесены во внешний файл конфигурации, который игнорируется Git.

## Использование

1. Скачать проект с репозитория.
2. Добавить файл config.json, в котором должно быть следующие содержание:
{
  "SourceFolder": "C:\\",
  "BackupFolder": "D:\\MyBackups"
}
Где SourceFolder - папка из которой будут копироваться файлы, а BackupFolder куда они будут копироваться.
3. Запустить приложение.
